## Решения по ходу (ADR 0022)
- Контракт 1.8.0 (п. 15): в `Vehicle` не было id модели для фильтра статей.
- `scripts/integration_stack.sh <образ> -- <команда>`: E2E клиента на том же стеке, свой тестовый номер
  (сценарий backend блокирует своего клиента).
- У тестовых номеров та же пауза между запросами кода (60 с), что у обычных: повторный вход в `api_e2e`
  проверяет `RATE_LIMITED` и ждёт `Retry-After`.

- Шрифт Inter (ADR 0022 п. 9): релиз 4.1 из github.com/rsms/inter (загрузка разрешена владельцем
  2026-10-12), статические начертания 400/500/600/700 — Flutter сопоставляет их с `FontWeight` без осей
  вариативного шрифта. Inter шире Roboto, на котором мерили вёрстку в главе 9: подписи схемы агрегатов
  расширены (центральные 104 → 108, боковые 76 → 78), тест вёрстки — на метриках Inter.
