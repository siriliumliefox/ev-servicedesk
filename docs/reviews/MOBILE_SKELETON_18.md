## Решения по ходу (ADR 0022)
- Контракт 1.8.0 (п. 15): в `Vehicle` не было id модели для фильтра статей.
- `scripts/integration_stack.sh <образ> -- <команда>`: E2E клиента на том же стеке, свой тестовый номер
  (сценарий backend блокирует своего клиента).
- У тестовых номеров та же пауза между запросами кода (60 с), что у обычных: повторный вход в `api_e2e`
  проверяет `RATE_LIMITED` и ждёт `Retry-After`.

- Шрифт Inter (ADR 0022 п. 9): релиз 4.1 из github.com/rsms/inter (загрузка разрешена владельцем
  2026-10-12), статические начертания 400/500/600/700 — Flutter сопоставляет их с `FontWeight` без осей
  вариативного шрифта. Inter шире Roboto, на котором мерили вёрстку в главе 9: подписи схемы агрегатов
  расширены (центральные 104 → 108, боковые 76 → 78), тест вёрстки — на метриках Inter.

## Проверка на устройстве (DoD)
- **Устройство:** iPhone 17 Air, iOS 27.0; release-сборка, бесплатная подпись Personal Team.
- **Стек:** `mobile/scripts/device_run.sh` — backend из образа-кандидата (сценарий backend перед этим — PASS),
  открыт в локальной сети, приложение — `http://MacBook-Pro-Sirilium.local:18080`.
- **Сценарий 1 (Wi-Fi), владелец — всё PASS:** телефон → код → согласие ПД → VIN `L6TZ0011234567890` → главный
  экран Zeekr 001 → карточка («Работ пока не было») → пробег 1500, затем 1000 — «Не меньше текущего» →
  перезапуск без SMS → профиль (телефон) → выход.
- **Сценарий 2 (Network Link Conditioner, Edge) — PASS:** вход тем же номером, индикаторы загрузки вместо пустых
  экранов; авиарежим → «Повторить» → «Нет подключения к интернету».
- **Сверка на сервере (БД стека):** у клиента одно авто `L6TZ0011234567890`, пробег 1500 (уменьшение не записано);
  refresh-токенов 3 — первый вход, ротация при перезапуске без SMS, вход под Edge; действует один — выход отозвал
  прежнюю сессию.
- Попутно: вывод команды после «--» в `scripts/integration_stack.sh` — построчный (`sed -l`/`-u`), иначе код
  для входа появлялся только после остановки стека; Personal Team — в локальном
  `ios/Flutter/DeveloperTeam.xcconfig` (не в git).
