## Заметки ведущего (стенд, инструмент)
1) Артефакт стенда, ввод текста. Аппаратная раскладка симулятора русская, поэтому латиница из action "text" приходила кириллицей ("Versiya navigatora 6.12" превратилось в "Мука шеф тфмшпфещкф 6ю12"). Поле VIN молча отбрасывало все не-VIN символы, оставались только цифры ("2000123"). VIN в итоге вставлен через буфер; системный диалог iOS «Разрешить вставку … из CoreSimulatorBridge» подтверждал ведущий. В чате C7 вставка кириллицы дала кракозябры. Чтобы очистить поле, ведущий вышел из чата и вернулся. Затем ответ набран латинскими клавишами под русскую раскладку («Dthcbz yfdbufnjhf 6&12» дало «Версия навигатора 6.12»). Ничего из этого не считалось в taps/errors персоны. Побочное наблюдение (не засчитано): поле VIN без подсказки «переключите раскладку» молча удаляет кириллические буквы. На реальном телефоне с русской клавиатурой это может запутать. 2) Протокол. Часть ранних скриншотов (C1–C3) выпала из контекста агента из-за лимита изображений. Чтобы точно восстановить тексты экранов, ведущий пересмотрел собственные сохранённые снимки экрана этой сессии (только изображения экрана). Код, документацию и тесты не открывал. Снимки других сессий не открывал. 3) Шаг ведущего C1: иконку «Демо» пришлось открывать повторно, «Без авто» выбрано, панель закрыта тапом по затемнению. 4) C1, важно.
