## Проверка полноты

22 действия; у каждого есть минимум одна роль с доступом — PASS (ручная проверка, 2026-10-08).

## Решения

- **RBAC-01 (2026-10-08, владелец проекта).** `updateVehicleMileage`: `engineer` может менять пробег только автомобиля, который связан с тикетом, назначенным этому инженеру; иначе `403`. `client` — только свой автомобиль, `admin` — любой. Реализация — object-level проверка в сервисном слое и тесты; правило описано в `description` эндпоинта в `openapi.yaml`.
