## Проверка полноты

25 действий; у каждого есть минимум одна роль с доступом — PASS (автоматически: `backend/tests/contract/test_openapi_contract.py`, 2026-10-10).

## Решения

- **RBAC-01 (2026-10-08, владелец проекта).** `updateVehicleMileage`: `engineer` может менять пробег только автомобиля, который связан с тикетом, назначенным этому инженеру; иначе `403`. `client` — только свой автомобиль, `admin` — любой. Реализация — object-level проверка в сервисном слое и тесты; правило описано в `description` эндпоинта в `openapi.yaml`.
- **RBAC-02 (2026-10-10, владелец проекта, ADR 0006).** `correctVehicleMileage` (уменьшение пробега) — только `admin`, с обязательной причиной; запись в append-only журнале. `withdrawPdConsent` — только `client`, своё согласие. Роль проверяется в сервисном слое (403), для корректировки пробега дублируется триггером БД.

- **RBAC-03 (2026-10-10, владелец проекта, Глава 3).** «Фиксация текущей прошивки авто» (`setVehicleFirmware`) — `engineer` и `admin`; строка добавлена, поведение контракта не менялось. `registerPushToken`/`deletePushToken` — только `client`, как в строке «Получение push-уведомлений» (служебные push инженерам — вне v1). «Нет (чтение)» и «Нет (только просмотр)» означают доступ к GET-операциям.
