# Глоссарий

Текстовая копия раздела 2 приложения `docs/Prilozhenie_Glava1_EV_ServiceDesk.docx`. Статус: BASELINE v1 — утверждён владельцем проекта 2026-10-08 (ADR 0002).

| Термин | Определение |
|---|---|
| VIN | Идентификационный номер автомобиля (17 символов); привязка авто к аккаунту и автозаполнение марки/модели/комплектации. |
| Агрегат | Контролируемый узел/расходник авто (масло двигателя, масляный/воздушный/салонный фильтр, масло редуктора, фреон кондиционера); список расширяется через админ-панель. |
| Регламент ТО | Заданный администратором для модели авто интервал (пробег/время) до плановой замены агрегата; не «зашит» в код. |
| Статус «светофор» | Расчётное состояние агрегата: зелёный — заменено (до 70% интервала), жёлтый — скоро менять (70–100%), красный — требуется замена (>100%). |
| Цифровой паспорт автомобиля | Раздел клиентского приложения: интерактивная схема агрегатов, история ТО, статусы. |
| Тикет | Обращение клиента в поддержку: категория (Навигация/Звук/SIM-связь/Сбой приложения/Агрегаты-ТО), статус, история переписки. |
| Статус тикета | Отдельная от статуса агрегата величина: Новый → В работе → Ожидает вендора → Решено (`new`, `in_progress`, `waiting_vendor`, `resolved`). |
| SLA | Целевой норматив обработки обращения (напр. первичный ответ — до 15 минут). |
| Дерево решений | Пошаговый сценарий самопомощи по типовой ошибке с точкой эскалации в тикет. |
| База знаний | Статьи/инструкции для клиента («Обучение») и готовые ответы для инженера. |
| Прошивка | ПО мультимедийной системы авто; уведомления информационные, удалённая перепрошивка не выполняется. |
| Русификация | Услуга компании по адаптации мультимедиа на русский язык; после неё клиенту устанавливается приложение. |
| RBAC | Модель разграничения доступа по ролям на уровне API. |
| Роль | Клиент (`client`) / Инженер поддержки, оператор (`engineer`) / Администратор (`admin`). |
| Push-уведомление | Сообщение через Firebase Cloud Messaging (прошивка, ТО, новости/акции). |
| VIN-декодер | Внешний сервис/API определения марки/модели по VIN. |
| Канбан-доска | Инструмент инженера: тикеты, сгруппированные по статусу/приоритету/SLA. |
| Остаток ресурса | Расчётное значение (км/дни) до порога замены агрегата. |
| Uptime | Доля времени доступности системы (цель — не менее 99.5%). |
| WCAG | Стандарт доступности; в ТЗ — контраст текста не менее 4.5:1. |
| MoSCoW | Метод приоритизации: Must / Should / Could / Won't have. |
| MVP | Минимально жизнеспособный набор функций первого релиза. |
| DoD | Definition of Done — согласованный критерий завершённости этапа/главы. |
