# 0002. Baseline требований утверждает владелец проекта

**Статус:** Принято, 2026-10-08

## Контекст
`MASTER_CHECKLIST.md`, глава 1, требует sign-off требований с руководителем/заказчиком и стороннее ревью глоссария. Владелец проекта решил не проводить формальные подписи и внешнее ревью.

## Варианты
1. Ждать подписей и стороннего ревью.
2. Baseline утверждает владелец проекта; фиксация — merge PR и Git-тег.

## Решение
Вариант 2. Владелец утвердил 2026-10-08: бэклог (включая N-01…N-10), глоссарий, RBAC-матрицу, коды `aggregate_type` (`engine_oil`, `oil_filter`, `air_filter`, `cabin_filter`, `gearbox_oil`, `ac_refrigerant`) и правило RBAC-01 для `updateVehicleMileage`. Baseline фиксируется тегом `requirements-baseline-v1`.

## Последствия
- Пункты «sign-off» и «ревью сторонним человеком» главы 1 закрываются этим ADR.
- Раздел 4 «Сигн-офф» в `.docx` остаётся для диплома незаполненным и не является блокером.
- Изменение baseline — только через PR с обновлением `docs/requirements/` и новым тегом версии.
- Seed `aggregate_type` — в главе 2 через Alembic; RBAC-01 — в главе с бизнес-логикой автомобилей.
