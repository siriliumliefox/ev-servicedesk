# 0010. Дизайн-токены: источник истины, бренд, темы, Figma на Starter

**Статус:** Принято, 2026-10-10 (владелец проекта, Issue #34)

## Контекст
Глава 6 требует палитру с контрастом ≥ 4.5:1, типографику для mobile и web, тап-зоны ≥ 44×44,
шкалу отступов, тёмную тему инженера и библиотеку компонентов Figma. Интерфейсы три: Flutter (клиент),
React + Tailwind v4 (инженер, админ). На момент аудита `StatusBadge` использовал палитру Tailwind по
умолчанию без иконки, тем не было. Владелец потребовал брендовый primary головного филиала ETS AUTO
(https://ets-auto.by): `--primary: #f9ce12`, текст `#171717`, шрифт Inter (заголовки сайта — Sora).
Figma — тариф Starter (Education запрошен): 1 режим на коллекцию переменных, 3 страницы, публикация
командной библиотеки недоступна, лимит вызовов MCP.

## Варианты
- **Источник истины:** Figma Variables → экспорт в код / файл токенов в репозитории → генерация кода
  и ручной перенос в Figma / значения отдельно в каждом клиенте.
- **Формат:** W3C Design Tokens (DTCG) / Style Dictionary / собственный.
- **Генерация:** Style Dictionary / собственный скрипт на Node без зависимостей.
- **Тёмная тема в вебе:** класс `dark:` Tailwind на каждом элементе / семантические CSS-переменные,
  переключаемые атрибутом `data-theme`.
- **Брендовый жёлтый:** как цвет текста / только заливка с тёмным текстом.
- **Шрифт:** Inter + Sora (как на сайте) / только Inter / системный.

## Решение
1. **Источник истины — `design/tokens.json` (DTCG)** в репозитории: примитивы `color.*`, семантика
   `theme.light|dark.*`, `typography.mobile|web.*`, `space`, `radius`, `size`, `shadow`, `duration`.
   Figma — производное представление (Variables собираются из файла). Изменение токена: `tokens.json` →
   `npm run tokens` → Figma.
2. **Генератор — `scripts/design_tokens.mts`** (Node ≥ 22.18, без зависимостей): `web-shared/src/theme/tokens.css`
   (Tailwind v4 `@theme`, палитра и шкалы Tailwind по умолчанию отключены) и `mobile/lib/theme/tokens.g.dart`
   (`EvColors` — `ThemeExtension`, `EvSpace`, `EvRadius`, `EvSize`, `EvTypeMobile`). Сгенерированные файлы
   коммитятся; `npm run test:tokens` в CI (`web-ci`) проверяет их синхронность, контраст WCAG, сетку,
   тап-зоны и различимость статусов. Style Dictionary отклонён: два целевых формата, лишняя зависимость.
3. **Темы — семантические токены.** Веб: `bg-surface`, `text-fg`, … → `var(--ev-*)`; тема — атрибут
   `data-theme` на `<html>`, без атрибута — `prefers-color-scheme`. Кабинет инженера по умолчанию тёмный
   (ТЗ раздел 6), выбор хранится в `localStorage`. Flutter: `evTheme(Brightness)`.
4. **Бренд ETS AUTO:** `#f9ce12` только заливка (кнопка primary, индикатор навигации) с текстом `#171717`
   (11.8:1); на белом он даёт 1.5:1, поэтому для ссылок и акцентного текста — `#7a5c00` (6.25:1).
   Статус «скоро менять» — янтарный (`amber`), а не брендовый жёлтый: оттенок отличается (тест ≥ 10°),
   статус всегда с иконкой-треугольником и подписью.
5. **Только Inter** (OFL, кириллица): в вебе — `@fontsource-variable/inter` из npm (без запросов к
   Google Fonts); во Flutter — системный шрифт до подключения ассета Inter в главе 18. Sora отклонён —
   нет кириллицы.
6. **Figma на Starter — временные обходы:** тёмная тема — отдельная коллекция `Color Dark` с теми же
   именами, что `Color Light`; Cover и Foundations — одна страница; библиотека доступна по ссылке, но не
   опубликована. После перехода на Education: объединить в коллекцию `Color` с режимами Light/Dark,
   разнести страницы, Publish — тогда закрывается DoD главы 6.

## Последствия
- Цвет, отступ или радиус «мимо» токенов в вебе не скомпилируется в утилиту (палитра Tailwind отключена);
  во Flutter — доступны только `EvColors`/`Ev*`.
- Контраст проверяется автоматически на каждом PR; проверка плагином Stark в Figma — ручная (владелец).
- Пока Figma на Starter, пункт DoD «библиотека опубликована» — `PARTIAL`.
